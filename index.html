백업 · 가져오기

JSON에는 일정과 기록이 모두 들어갑니다. 파일은 개인정보이므로 안전하게 보관해 주세요.

가져오기는 기존 자료와 합칩니다. 같은 ID는 더 최신인 자료로 갱신합니다. 삭제된 자료는 백업으로 되살릴 수 있습니다.

Google Drive 백업 · 복원

연결할 때만 Google에 접속합니다. 처음 연결 준비가 끝나면 Google 연결 버튼을 한 번 더 눌러 주세요. 승인하면 일정·기록 백업을 본인 Drive의 앱 전용 공간에 저장합니다.

연결되지 않았습니다. JSON 백업은 연결 없이 사용 가능합니다.

Google Cloud 설정 3단계
  1. Google Cloud Console에서 프로젝트를 만드신 뒤 ‘API 및 서비스 → 라이브러리’에서 Google Drive API를 사용 설정하세요.
  2. ‘Google Auth Platform’에서 앱 이름과 본인 이메일을 등록하세요. 대상이 외부이고 테스트 상태라면 본인 Google 계정을 테스트 사용자로 추가하세요. 데이터 액세스 범위는 https://www.googleapis.com/auth/drive.appdata 입니다.
  3. ‘클라이언트’에서 OAuth 클라이언트 ID를 ‘웹 애플리케이션’으로 만드세요. 승인된 JavaScript 원본에 아래 원본 주소를 등록하고 발급된 Client ID만 위에 붙여 넣으세요. Client Secret은 입력하지 않습니다.

연결이 안 되면 ‘JSON 백업 내려받기’로 완성된 백업 파일을 저장하고, 원하시면 Google Drive 웹사이트에 직접 올리세요. 복원은 그 파일을 내려받아 ‘JSON 백업 가져오기’로 하시면 됩니다.
